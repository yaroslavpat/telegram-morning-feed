# Scheduled task: утренняя Telegram-лента

Каждый день в 10:00 по Самаре обновляй публичную страницу утренней Telegram-ленты для Яро в этом репозитории. Корень проекта — текущая папка репозитория. Публикуемый файл — `index.html`; GitHub Pages публикует сайт через GitHub Actions.

## Сборка и публикация

1. Используй `TelegramChannels.opml` как список каналов. Запусти `python3 build_telegram_feed.py 48`. Скрипт сохраняет публикации за последние 48 часов в `work/telegram_posts.json` и печатает статистику `channels=… posts=… quiet=… failed=… images=…`.
2. Не создавай и не используй LLM-саммари, Top-3 или другой сгенерированный редакционный блок. Рендерер собирает страницу только из постов; JSON саммари не нужен.
3. Если `posts=0` и `failed` больше половины каналов, не меняй и не публикуй страницу. Сообщи статистику и остановись. Если постов нет по иной причине, сформируй страницу с доступными данными.
4. Запусти `python3 render_telegram_feed.py`.
5. Проверь HTML: документ и заголовок присутствуют; нет блока Top-3/саммари; обе кнопки фильтров 🔪 и 🐝 находятся справа сверху и активны по умолчанию (посты соответствующих каналов скрыты); маяк загружается из `assets/lighthouse.png` возле заголовка и строки количества постов; время отображается по Самаре; посты сохраняют аватары, медиа, ссылки и форматирование; «Читать полностью» раскрывает продолжение без повтора, пропуска или многоточия; в тексте и ссылках нет пробелов перед знаками пунктуации. Убедись, что `index.html` не превышает 15 МиБ. Если размер больше, пересобери публикации за 36 часов, отрендери повторно и проверь размер ещё раз.
6. Если `posts=0` и более половины каналов недоступны, оставь опубликованную страницу без изменений. В остальных случаях сохрани итоговую страницу в `main` и отправь в `origin`; GitHub Actions должен завершить публикацию GitHub Pages. Если отправка или деплой не удались, скажи об этом прямо и не утверждай, что сайт обновился.

В итоговом сообщении укажи число постов, строку статистики сборщика, список каналов с ошибками и результат публикации. Саммари и заголовки выбранных постов не нужны.
