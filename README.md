# Telegram Morning Feed

Публичная страница утренней Telegram-ленты для чтения с телефона. Источник списка каналов — `TelegramChannels.opml`.

## Ежедневная сборка

Из корня проекта запусти:

```sh
python3 -m pip install -r requirements.txt
python3 build_telegram_feed.py 48
```

Саммари не используются. Создай пустой файл `work/telegram_summary.json` и собери страницу:

```sh
mkdir -p work
printf '[]\n' > work/telegram_summary.json
python3 render_telegram_feed.py
```

Результат — `index.html`. GitHub Actions также собирает и публикует ленту ежедневно в 10:00 по Самаре; компьютер для этого не нужен. Публикация проходит через настроенный GitHub Pages workflow.

Сборщик сохраняет встроенные ссылки и форматирование текста Telegram, удаляет пробелы перед знаками препинания и загружает аватарки и медиа. Страница отображает время Самары, имеет переключатель фильтра «Нож» и «Пчела» и бесшовно раскрывает длинные посты. На iPhone карточки идут от края до края, аватар и заголовок находятся над текстом, а текст занимает всю ширину карточки.
