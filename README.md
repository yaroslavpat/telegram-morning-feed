# Telegram Morning Feed

Публичная страница утренней Telegram-ленты для чтения с телефона. Источник списка каналов — `TelegramChannels.opml`.

## Ежедневная сборка

Из корня проекта запусти:

```sh
python3 -m pip install -r requirements.txt
python3 build_telegram_feed.py 48
```

Саммари и Top-3 не используются. Собери страницу:

```sh
python3 render_telegram_feed.py
```

Результат — `index.html`. GitHub Actions также собирает и публикует ленту ежедневно в 10:00 по Самаре; компьютер для этого не нужен. Публикация проходит через настроенный GitHub Pages workflow.

Сборщик сохраняет встроенные ссылки и форматирование текста Telegram, удаляет пробелы перед знаками препинания и загружает аватарки и медиа. Страница отображает время Самары, имеет отдельные компактные фильтры 🔪 и 🐝 (оба канала скрыты по умолчанию), показывает маяк `assets/lighthouse.png` в шапке и бесшовно раскрывает длинные посты.
